# News entries

One Markdown file per announcement, named `YYYY-MM-DD-slug.md`. The section
(page, RSS feed, nav entry, home teaser) only exists while at least one entry
is here. Format — see `EXAMPLE.md.txt`:

```
---
title: QtDMM 1.0 released
date: 2026-09-25
link: https://github.com/qtdmm/QtDMM/releases/tag/v1.0.0   (optional)
---
Body in Markdown: paragraphs, lists, links, `code`.
```
