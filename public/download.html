Building from source

Requirements: a C++17 compiler, CMake ≥ 3.16, Qt 6 with the SerialPort and Charts modules, and hidapi for USB‑HID cables (fetched automatically if not installed).

git clone https://github.com/tuxmaster/QtDMM.git
cd QtDMM
./compile.sh          # configure + build into build/
./compile.sh run      # build and start
./compile.sh pack     # .deb + source tarball

Debian/Ubuntu: sudo apt install build-essential cmake qt6-base-dev qt6-serialport-dev qt6-charts-dev libhidapi-dev

Arch: sudo pacman -S cmake qt6-base qt6-serialport qt6-charts hidapi — or use the PKGBUILD in the repository.

macOS: brew install cmake qt hidapi, then the same steps.

FreeBSD: pkg install cmake qt6-base qt6-serialport qt6-charts hidapi.

Serial port permissions

On Linux, add yourself to the group that owns the port — dialout on Debian/Ubuntu/Fedora, uucp on Arch — and log in again. QtDMM tells you which group it needs if a port cannot be opened. Details are in the troubleshooting page.
