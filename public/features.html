Features

What QtDMM does

A readout that looks like an instrument, a recorder that behaves like a chart recorder — and a device list that saves you from guessing baud rates.

Analog meter

A procedurally drawn needle instrument in the style of a studio VU meter: dark or ivory face, mirrored‑scale ballistics on the needle, a red overrange zone and an OL lamp that lights when the meter reports overload.

  • Auto‑ranging scale that follows the meter's range and unit
  • Bipolar scale for signed readings, min/max marks on the scale, secondary readout
  • HOLD indicator, current/max fields
  • Dockable panel — stack it, float it, or run it full‑screen on a second display

LCD display

Seven‑segment digits on a warm LCD‑green face with ghost segments, a 40‑segment bargraph and the annunciators you know from the meter itself: HOLD, AUTO/MANU, AC/DC, diode, continuity, REL.

  • Main value plus MIN and MAX lines
  • Scales with the window, from a corner widget to a wall display
  • Same dockable panel frame as the analog meter

Transient recorder

Built on Qt Charts. Record a battery discharge over a weekend or a thermistor over a minute — the sample rate and window length are yours.

  • Start manually, at a set time, or automatically when a rising/falling threshold is crossed
  • Three draggable threshold lines, cursor crosshair with live readout
  • Integration curve (running sum — Ah, Wh, …)
  • Mouse‑wheel zoom, middle‑button pan
  • Export as CSV, Excel (.xlsx) or OpenDocument (.ods) — real date and number cells, bold frozen header, ready for charts and formulas; CSV import with SI prefixes (µ, m, k, M …); printing
  • Export the graph itself as SVG, PDF, PNG or JPEG — see below
  • Run an external command when a threshold is hit

Readings table

A third dockable panel (Ctrl+4) lists every reading the meter sends, one row each: time to the millisecond, value as displayed, unit, mode, range, HOLD. Where the recorder samples on a fixed grid, this is the raw protocol of the session.

  • Follows the newest reading; pauses while you scroll back, or with the pause button
  • Statistics line: count, min, max, mean, span
  • Ctrl+C copies selected rows tab‑separated straight into a spreadsheet
  • Export as CSV, Excel or OpenDocument (timestamp, value, unit, mode, range, hold, alarm), keeps the newest 10 000 rows by default

Alarms

Tell QtDMM what you expect — below 12 V, above 2 A, no readings for 10 s — and it acts when the reading leaves that range. Each instance keeps its own list under Settings → Alarms.

  • Conditions: reading below / above, outside or inside a range, overload, no readings for N seconds
  • No chatter: for at least N s ignores spikes, a hysteresis keeps a raised alarm from flapping
  • Actions, any combination: banner over the graph with Acknowledge, beep, popup, bring the window to front, start or stop the recorder, mark in the graph and the readings table
  • Run a program with %v, %u, %n — the hook for notify‑send, mail, a webhook or a relay

Connection backends

  • RS‑232 serial — native UART or USB‑serial adapters (PL2303, FTDI, CH340 …)
  • USB‑HID cables — Uni‑Trend UT‑D04 (HE2325U / CH9325) and UT‑D09 (CP2110 / CH9329), Brymen BU‑86X for the BM52x/BM82x/BM86x; no driver needed
  • RFC2217 remote serial — the meter sits next to the device under test, QtDMM sits on your desk. qtdmm‑bridge, a single Python file shipped with QtDMM, serves serial and USB‑HID meters from a Raspberry Pi; QtDMM sends the line settings itself, so any supported meter works through it. Runs as a systemd service, announces itself via mDNS, and QtDMM's Find bridges button lists every bridge on the network. Details in the handbook.
  • Bluetooth LE — Victron SmartShunt / BMV‑712, SmartSolar / BlueSolar MPPT and Phoenix Inverter Smart via their encrypted Instant Readout broadcasts; no pairing, key from the VictronConnect app, choose which value is the reading and which the second value. Handbook.
  • sigrok‑cli — SCPI bench meters (Keysight 34465A, Agilent 34405A/34410A/34460A, HP 34401A, Siglent SDM3055, or any scpi-dmm model) and every other meter sigrok supports, via USB‑TMC, GPIB or serial. Needs sigrok‑cli installed separately (how); details in the handbook.

Picking a vendor and model fills in baud rate, parity, stop bits and the control lines the cable needs. Unknown meters: choose Manual settings and a protocol. QtDMM notices when a meter goes quiet or a connection is lost — cable, bridge or network — and reconnects on its own as long as Connect is pressed.

Several meters, one desk — and calculated values

Run one QtDMM per meter. Instances find each other and can be started and stopped together, so voltage and current recordings line up. A third instance can calculate from the others: choose the model QtDMM / Calculated value, give it a unit and a formula such as u * i, and it behaves like any meter — display, needle, recorder, export.

  • Operators, parentheses, SI suffixes (1.5k, 22u), sqrt, abs, log10, min/max …
  • Inputs are combined in base units; the result gets a fitting prefix (12 V × 0.5 mA = 6.00 mW)
  • Shows OL and names the missing input when a meter drops out

The graph as a file — SVG, PDF, PNG, JPEG

Export image… in the graph's context menu writes the recording to a file. SVG and PDF keep the curve, the grid, the axes and their labels as vectors: sharp at any size, editable in Inkscape, and ready to drop into a document, a paper or a web page. PNG and JPEG are pixels, for when a picture is all you need.

The SVG carries the recording's start time, its number of values, the sample rate and the unit as title and description — so the file still says what it shows a year later. The picture on the left is not a screenshot: it is such an export, straight from the running program — 1120 readings with the integration curve on top, as vectors, so zoom in as far as you like.

Virtual meter

Pick the model QtDMM / Virtual meter and QtDMM generates a value itself. Two things it is good for: testing — try the panels, the recorder and thresholds, or give a demo without any hardware — and standing in for a meter you don't have.

Typical case: a bench supply with its own voltage readout and one real DMM measuring the current. For power you would need a second meter — instead, set a virtual meter to the supply's fixed voltage and let a calculated instance multiply it with the live current. Not lab‑grade, but as long as the supply is regulated and not at its limits it is all you need. The same trick supplies a constant for temperature compensation, a probe factor, or a simulated sine for trying out a formula.

  • Waveforms: constant, random, sine, triangle, square, sawtooth, discharge curve (like a battery under load) — or your own formula
  • Min, max, period and noise amplitude; unit and coupling of your choice
  • Publishes its value like a real meter, so u * i works with a virtual u

SCPI server — QtDMM as a network instrument

QtDMM answers *IDN?, READ?, CONF? and friends on a TCP port (5025, lxi‑tools style). A consumer multimeter on a USB cable, a Victron device over Bluetooth or the virtual meter becomes a network instrument for lxi‑tools, PyVISA, LabVIEW or five lines of Python. Announced by mDNS (_scpi-raw._tcp), so lxi discover -m finds it.

  • INITiate / ABORt start and stop the recorder, INPut ON|OFF connect and disconnect
  • HCOPy:SDUMp:DATA? returns a screenshot of the QtDMM window — like a bench meter's screen dump
  • Read‑only towards the meter, off by default, localhost‑only unless you open it up

Handbook, shortcuts, command line

The manual is embedded in the program (F1, searchable with Ctrl+F) and published at qtdmm.de/docs; developers find the API reference at qtdmm.de/api. Every action has a keyboard shortcut, shown in its tooltip: Space starts and stops the recorder, Ctrl+Del clears it, F11 goes full screen — the complete list is grouped by window.

Interface languages: English, German, French, Spanish and Polish.
