QtDMM has a new home: github.com/qtdmm

QtDMM now lives in its own GitHub organization: github.com/qtdmm/QtDMM. tuxmaster, who carried the project since the Qt 5 port, transferred the repository there, so nothing was lost: history, releases, issues, stars and forks came along, and the old address github.com/tuxmaster/QtDMM redirects automatically. Existing clones keep working; to point yours at the new address:

git remote set-url origin https://github.com/qtdmm/QtDMM.git

The organization gives the project what a single account cannot: shared maintenance, roles, and a home that does not depend on one person. Together with this website it is the place for releases, bug reports, new meters and pull requests.

Thanks to tuxmaster for years of keeping QtDMM alive — and for handing it over so cleanly.
