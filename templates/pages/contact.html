Bug reports & feature requests

Open an issue on the project page. Please include your operating system, the meter model and cable, and — for decoding problems — the raw bytes from qtdmm --debug.

Adding a meter

If your meter speaks one of the known protocols it usually only needs a new entry with the right serial settings. Otherwise a protocol capture (a few readings in each mode) lets us write a decoder. The developer pages explain how; the API reference (Doxygen) documents the decoder and port classes.

⑂

Contributing

Pull requests are welcome: code, translations, packaging for your distribution, or a confirmation that your meter works. Fork tuxmaster/QtDMM on GitHub, work on a branch and open a pull request against it.
