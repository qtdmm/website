Building from source

Requirements: a C++17 compiler, CMake ≥ 3.16, Qt 6 with the SerialPort and Charts modules, and hidapi for USB‑HID cables. Three CMake commands do the job:

git clone https://github.com/qtdmm/QtDMM.git
cmake -S QtDMM -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Package lists for Debian/Ubuntu, Fedora, Arch, FreeBSD, macOS and a walkthrough for Windows are on the Docs & Dev page.

Bench meters via sigrok

Meters listed with the protocol Sigrok (Keysight, Agilent, HP, Siglent bench meters and any other scpi-dmm model) are read through sigrok‑cli, which is not part of QtDMM and has to be installed separately: sudo apt install sigrok-cli (Debian/Ubuntu), sudo pacman -S sigrok-cli (Arch), brew install sigrok-cli (macOS), pkg install sigrok-cli (FreeBSD); Windows builds are on the sigrok download page. QtDMM finds it in PATH or you set the path under Settings → Special ports. The driver string for your meter is in the sigrok hardware list; the handbook page Bench meters through sigrok‑cli walks through the setup.

Serial port permissions

On Linux, add yourself to the group that owns the port — dialout on Debian/Ubuntu/Fedora, uucp on Arch — and log in again. QtDMM tells you which group it needs if a port cannot be opened. Details are in the troubleshooting page.
